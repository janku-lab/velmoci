# Velmoci 1901

Česká webová verze deskové hry Diplomacie – mapa Evropy 1901, sedm velmocí, rozhodčí tahů, ústupy, stavby, boti, tutoriál a přehrávání kol.

**Hrát:** https://velmoci.danieljanku.cz/ (Netlify, nasazuje se automaticky z větve main; záloha https://janku-lab.github.io/velmoci/)

Na webu se hraje online s přáteli (Firebase), volná místa berou boti. AI diplomaté fungují jen ve verzi v Claude.

Struktura a pravidla pro úpravy viz [CLAUDE.md](CLAUDE.md).
